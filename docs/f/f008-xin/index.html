车站重逢的记忆 20世纪90年代 北方火车站

记忆里的故事

九十年代北方的冬天，老火车站站台的残雪冻得硬邦邦，风呼呼地往衣领里钻。几位老伙计赶路途中意外撞上，当场上演一场热闹的老友重逢！ 厚厚的棉帽裹住脑袋，大衣领口高高立起。两人大手紧紧握在一起，使劲晃了晃，脸上笑得眼角都皱起来，旁边兄弟顺势一胳膊搭住肩头，热热闹闹凑成一团。 手边的帆布大包鼓鼓囊囊，网兜兜着被褥家当，一看就是长途赶路。那时候电话难得打，书信往来又慢，谁也没想到能在这冷冰冰的车站偶遇。 一路奔波的疲惫一下子全没了。天寒地冻又怎么样，老哥们碰面，话匣子一下打开，家长里短、过往趣事一股脑往外倒。站台上寒风凛冽，可这一群人的欢声笑语，直接把冬日的寒气都赶跑。这一场不期而遇的碰面，算是赶路途中捡到的大惊喜！
