一碗羊杂汤里的想念

那碗汤，成了藏在岁月里最深的想念。

羊杂汤 少年时期 镇上

记忆里的故事

少年时候，爸爸要外出务工。临行那天在镇上，他特意给我买了一碗热腾腾的羊杂汤。汤冒着白汽，鲜香扑鼻，我捧着碗大口喝着，爸爸站在一旁看着我，叮嘱我在家好好听话。 喝完汤，我站在路口，望着爸爸背着行囊越走越远，心里盼着他早日平安归来。 可等到爸爸再回家，已经病倒了。昔日那个能带我喝羊杂汤的人，再也不能出门，也不会再为我买一碗羊杂汤。 如今我早已长大，偶尔路过镇上的老店，依旧会点一碗羊杂汤。味道还是当年的香气，只是再也没有爸爸陪在身边，那碗汤，成了藏在岁月里最深的想念。

记忆摘句那碗汤，成了藏在岁月里最深的想念。
