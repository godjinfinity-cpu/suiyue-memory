门前留影，送儿参军

这朵光荣花，是全家的荣耀。

参军合影 20世纪70年代 北方农家小院

记忆里的故事

七十年代的北方农家小院，土坯墙围着老宅，两杆二八自行车静静靠在墙边。今天，是家里大儿子要参军入伍的日子。 天刚亮一家人就忙开了。新军装熨得平平整整，胸前别着一朵大大的光荣花，红绸带子垂在衣襟上。他手里拎着部队配发的帆布提包，站在大门正中间，身姿挺得笔直。 一家人全都过来合影。父亲穿着朴素的中山装，神色庄重，藏着不舍，更多的是骄傲。母亲站在一旁，身上是家常的深色布褂，嘴角努力带着笑意，眼底却悄悄含着泪。旁边还有家里的姐妹、年幼的小弟，小弟小小的身子站在前排，手紧紧贴着裤腿，仰着头看哥哥。 村口的集合时间快要到了。这张在自家木门下拍下的黑白照片，就是留给家里的念想。 临行前，父亲反复叮嘱：到部队好好干，听首长的话，不能怕苦。母亲只一遍遍整理他的衣领，千言万语最后只化作一句照顾好自己。 快门按下，定格下这一刻。 这朵光荣花，是全家的荣耀。这张照片，留在老家的相框里，往后无数个日夜，家人看着相片，盼远方的儿子平安，盼他在军营建功。 多年以后，这张泛黄的老照片依旧保存完好。每次翻出来，还能想起那天清晨，土门前的阳光，自行车，还有一家人既不舍又满怀荣光的心情。

记忆摘句这朵光荣花，是全家的荣耀。
